# Wall.io - клиент

Итак, клиент игры. Писать будем на C# Avalonia UI, ориентируемся на платформы Desktop и Browser. Игра будет 2D (по крайней мере в первых версиях).
Первой задачей стоит сделать контрол основного меню, а также контрол игрового поля. Сначала сделаю offline игру без сервера, потом буду прикручивать сервак.
