# Wall.io

# Описание
Этот репо создан для создания PET проекта: игра Wall.io. Базовую концепцию я взял из игры Quoridor (https://ru.wikipedia.org/wiki/Коридор_(настольная_игра)?ysclid=mvn5fpmimm818060198). Я нахожу эту игру интересной с точки зрения простоты и гениальности в качестве базы для многопользовательской браузерной онлайн-стратегии, в которую можно накрутить очень много новых прикольных фитч и игровых механик. Основное назначение проекта, конечно, не игра сама по себе, а демо проект для возможных собеседований на позицию .NET C# Разработчика. Под это назначение проект выглядит хорошо, т.к. я себе архитектурно представляю возможным использовать в нём сразу очень много основных требуемых для вакансии навыков: PostgreSQL (бд для пользователей, профилей, и т.д.), Redis (быстрый доступ к метаданным активных игровых сессий, общей информации для всех пользователей вроде общего лидерборда и т.д.), к бд соответственно EF Core, для сервера ASP.NET, WEB API, EF Core, RabbitMQ, микросервисы, и т.д.. Для создания самой игры я возьму фреймворк, в котором у меня есть большой опыт разработки: Avalonia UI. Делать игру буду под Desktop + Browser (wasm). Писать код этого проекта собираюсь принципиально без использования нейронок, поэтому если в комментариях в коде вдруг начнутся анекдоты, которые я пишу просто для саморазвлечения в процессе, не стоит придавать этому много значения :)

# Архитектура
Как уже сказал в описании, бэкенд будет в виде микросервисов. Реляционная БД - Postgres. Быстрый кэш - Redis. Также нужно сразу закладывать возможность горизонтального масштабирования серверов, а значит сервер должен быть stateless по возможности. В качестве балансировщика нагрузки будет nginx на первое время, потом ближе к какому-то релизу можно будет плотнее заняться балансировкой нагрузки. Для первого наброска архитектуры, думаю, достаточно.
